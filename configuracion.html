Configuración Integral RAX

Nota: Los valores entre --TEXTO-- deben ser reemplazados por los datos reales del servicio.

1. Limpieza de Configuración (Modo Enable)

show vlan Verificar VLANs actuales en el equipo.
no vlan --ID-- Eliminar una VLAN específica (dentro de conf t).

2. VLANs, NNI y UNI (Entrar a conf t)

vlan --ID-- / state active / name --NOMBRE-- Crear y activar VLAN de Gestión o Servicio.
interface nni --PORT-- / switchport mode trunk Configurar puerto hacia la red (Uplink).
interface uni --PORT-- / switchport mode access Configurar puerto hacia el cliente.

3. IP de Gestión y Rutas

interface ip 0 / ip address --IP-- 255.255.255.0 --VLAN-- Asignar IP de administración a la VLAN de gestión.
ip default-gateway --GW-- Ruta de salida para modelos RAX711.

4. Seguridad TACACS+ (Acceso Remoto)

tacacs-server host --IP-- / tacacs-server key --KEY-- Configurar servidor y clave secreta TACACS.

5. Guardado Final (Importante)

write Guardar cambios en memoria flash (repetir 3 veces).
