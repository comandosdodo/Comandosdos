PASO 4: Configuración de Gestión IP

Explicación Técnica: La gestión se realiza sobre una interfaz lógica (interface ip 0). Es vital que la VLAN de gestión coincida con la configurada en el puerto NNI para tener acceso remoto.
interface ip 0Entrar a la interfaz virtual de administración del equipo.
ip address --IP-- 255.255.255.0 --VLAN--Asignar IP y asociarla a la VLAN de gestión.
Diferencia de Equipos (Rutas de Salida):
• RAX711 (4 Puertos): Utiliza el comando default-gateway.
• RAX701 (1 Puerto): Suele requerir una ruta estática 0.0.0.0.
ip default-gateway --GW--PARA RAX711: Configurar la IP del salto de salida.
ip route 0.0.0.0 0.0.0.0 --GW--PARA RAX701: Definir ruta por defecto para gestión.

PASO 5: Seguridad TACACS+ (Acceso Remoto)

Seguridad: Se debe configurar el servidor y luego habilitar aaa. Esto permite que el equipo valide usuarios centralizadamente pero mantenga el acceso local si el servidor falla.
tacacs-server host --IP--Dirección IP del servidor de autenticación.
tacacs-server key --KEY--Clave compartida definida para el nodo.
aaa authentication login default tacacs localLogin: Primero TACACS, si falla, usa base local.
aaa authentication enable default tacacs localModo Enable: Validación vía TACACS/Local.
aaa authorization exec default tacacs localAutorización para ejecutar comandos.
