Comandos Individuales RAX

1. Acceso y Limpieza

Globalconf t
VLANno vlan --ID--(Borrar VLAN antigua)
Portno switchport mode(Limpieza obligatoria)

2. Creación de VLANs

vlan --ID--
state active
name --NOMBRE--

3. Configuración de Interfaces

NNIswitchport mode trunk
NNIswitchport trunk allowed vlan --ID--
UNIswitchport mode access
UNIswitchport qinq dot1q-tunnel

4. IP y Gestión

interface ip 0
ip address --IP-- 255.255.255.0 --VLAN--
RAX711ip default-gateway --GW--
RAX701ip route 0.0.0.0 0.0.0.0 --GW--

5. Comandos TACACS (Uno a uno)

tacacs-server host --IP--
tacacs-server key --KEY--
aaa authentication login default tacacs local
aaa authentication enable default tacacs local

6. Finalizar

hostname --NOMBRE--
write(Ejecutar 3 veces)
