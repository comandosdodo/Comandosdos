Guía Técnica RAX (Paso a Paso)

Instrucciones: Sigue el orden de arriba hacia abajo. Reemplaza los valores marcados con -- por los datos del servicio.

PASO 1: Limpieza de Configuración Previa

show vlanVer qué VLANs borrar
conf tEntrar a configuración
no vlan --ID--Borrar VLAN de servicio/gestión
interface --PUERTO--Entrar al puerto a limpiar
no switchport modeResetear modo del puerto
no descriptionQuitar nombre anterior

PASO 2: Creación de Nuevas VLANs

vlan --ID--Crear ID de VLAN
state activeActivar VLAN
name --NOMBRE--Asignar nombre

PASO 3: Configuración de Puertos (NNI / UNI)

interface nni --PORT--Configurar puerto Trunk (Red)
switchport mode trunkHabilitar troncal
switchport trunk allowed vlan --ID--Permitir VLANs
interface uni --PORT--Configurar puerto Cliente
switchport mode accessModo acceso
switchport access vlan --ID--Asignar VLAN de servicio

PASO 4: IP de Gestión y Gateway

interface ip 0Entrar a interfaz lógica
ip address --IP-- 255.255.255.0 --VLAN--IP y VLAN de gestión
ip default-gateway --GW--Gateway (RAX711)

PASO 5: Configuración TACACS+

tacacs-server host --IP--IP del servidor
tacacs-server key --KEY--Clave secreta
aaa authentication login default tacacs localAutenticación
aaa authentication enable default tacacs localEnable
aaa authorization exec default tacacs localPermisos

PASO 6: Guardado y Verificación

exitSalir de configuración
writeGuardar (Hacerlo 3 veces)
